\sectiontitle{Introduction}
Clinical trials often involve low numbers of participants and are conducted in high-uncertainty environments. When data is sparse, it becomes more difficult to determine what treatment or action is optimal. Classical reinforcement learning (RL) treats participants independently while complete pooling ignores heterogeneity. Though complete pooling has been favored due to the bias-variance trade-off, it operates under the strong and inaccurate assumption that participants are homogeneous.

Empirical Bayes (EB) is a partial pooling strategy, which assumes that participants' parameters are drawn from an underlying hyperdistribution; in EB, the learning algorithm is run independently on each participant, but the action selection strategy is based upon this shared hyperdistribution. This approach has the potential to allow for individualized learning, while the action selection strategy can be stabilized by drawing information from all participants \autocite{doi:10.3102/10769986010002075}. The objective of this report is to evaluate EB's performance under various experimental settings.

Across all settings described in this write-up, there are $n$ participants denoted as $i = 1, i=2, \ldots, i=n$. There are $T$ decision times denoted as $t=0, t=1, \ldots, t=T$. All participants start at the same time; there is no staggered enrollment. Other attributes of the underlying environment, such as how the reward is generated, differ from setting to setting. 

We divide the RL algorithm into learning and decision-making components, which are separate from each other:

\textit{Learning algorithm.} Based on the action, reward, and if applicable, state and/or context of each individual participant observed at the prior time points, the learning algorithm will produce estimate(s) of some parameter(s) for that participant. The learning algorithm will also produce a measure of uncertainty for its estimate(s) of these parameter(s). The action selection strategy will receive each of the learning algorithm's parameter estimates and measures of uncertainty. 

\textit{Action selection.} After the learning algorithm has returned the parameters and measures of uncertainty, the action selection strategy will use pooled Thompson sampling (TS), unpooled TS, or empirical Bayes to determine actions for the participants ($A_{i,t}=a_{i,t}$). 
 Finally, based on the action selected, the underlying environment will generate the participant's reward ($R_{i,a,t}$), which may take on any real number.

The following write-up explores a vanilla multi-armed bandit (MAB) and a contextual bandit setting. Additionally, we present results of simulations based on the vanilla MAB setting. The theoretical formulations and simulation results for the vanilla MAB setting can be found in Section~\ref{sec:vanilla}, and the theoretical formulation for the contextual bandit setting can be found in Section~\ref{sec:context-var}. These section names describe the environment being tested, but it is important to recognize that we are also employing bandit algorithms, which are distinct from the bandit environment. 

\textit{Note.} In this write-up, the learning algorithm and/or action selection strategy often happens to have the correct model for the true environment. However, this is deeply unrealistic and would never occur in real world settings.\\

\sectiontitle{Vanilla Multi-Armed Bandit}
\label{sec:vanilla}

The vanilla MAB is often depicted as a gambler in front of slot machines (\enquote{arms}) who repeatedly pulls the arms to get rewards. In the vanilla MAB setting, participants have neither context nor state. Any parameters influencing the reward are constant for each participant regardless of time point, similar to how slot machine draws are not influenced by prior draws. 

Here, we specifically test a two-armed bandit.  At every time point, the algorithm must choose between two possible actions denoted as $a=0$ and $a=1$ respectively. 

\subsectiontitle{True Environment}

Each participant $i$ has one parameter for each arm: $\theta_{i,a=0}$ and $\theta_{i,a=1}$. These parameters vary from participant to participant and represent the true mean of a participant's reward distribution for that arm. When setting the environment, the \textit{participant-level means} $\theta_{i,a=0}$ and $\theta_{i,a=1}$ are random draws from \textit{population-level distributions}, where the true population-level mean for the two arms are denoted as $\mu_0$ and $\mu_1$. $\mu_0$ and $\mu_1$ may differ or be identical in value and are designated at the start of the simulation.
\begin{align*}
 \theta_{i,a=0} &\sim \mathcal{N}(\mu_{a=0}, \tau^2_{a=0})\\
 \theta_{i,a=1} &\sim \mathcal{N}(\mu_{a=1}, \tau^2_{a=1})
\end{align*}

At each time point $t$, the reward for each participant is determined by a random draw from the reward distribution corresponding to the arm selected for them by the action selection strategy. The reward distribution for each participant can be described as follows:
\[
R_{i,a,t} \sim \mathcal{N}(\theta_{i,a}, \sigma^2)
\]

This underlying environment contains two forms of variation—heterogeneity between participants ($\tau_a^2$) and noise within the measurements of each participant $i$ ($\sigma^2$)—which are also set at the start of the simulation. The values of both forms of heterogeneity can differ by arm.

\begin{lstlisting}[caption={Set environment.}, label={lst:setenv}]
// create true environment: theta ~ Normal(mu_a, tau_a^2)
// return n x arms matrix of parameters theta_{i, a}
Mat set_environment(int n, int arms, const Vec &mu_a, const Vec &tau_a, std::mt19937_64 &rng) {
    Mat theta(n, Vec(arms));
    for (int a=0; a<arms; ++a) {
        // draw n independent participant parameters for arm a 
        std::normal_distribution<double> d(mu_a[a], tau_a[a]);
        for (int i=0; i<n; ++i) theta[i][a] = d(rng);
    }
    return theta;
}
\end{lstlisting}

// Step 1: estimate population-level hyperparameters per arm
Vec mu_hat(2, 0.0), tau2_hat(2, 0.0);
for (int a = 0; a < 2; ++a) {
    // compute tau2_hat using simple mean
    // NOTE: unlike the write-up above, we use MOM instead of MLE to compute tau2 due to its lack of closed form MLE; see Nora's comment
    double mean_m = 0.0;
    for (int i = 0; i < n; ++i) mean_m += m[i][a];
    mean_m /= n;

    double var_m = 0.0;
    for (int i = 0; i < n; ++i) { double d = m[i][a]-mean_m; var_m += d*d; }
    var_m = (n > 1) ? var_m / (n-1) : 0.0;

    double mean_v = 0.0;
    for (int i = 0; i < n; ++i) mean_v += v[i][a];
    mean_v /= n;

    double est_tau2 = var_m - mean_v;
    if (est_tau2 < 0.0) est_tau2 = 0.0;
    tau2_hat[a] = est_tau2;

    // weighted mean for mu_hat: participants with lower uncertainty receive more weight
    double wsum = 0.0, wmsum = 0.0;
    for (int i = 0; i < n; ++i) {
        double w = 1.0 / (tau2_hat[a] + v[i][a]);
        wsum += w;  wmsum += w * m[i][a];
    }
    mu_hat[a] = (wsum > 0.0) ? wmsum / wsum : mean_m;
}

// Step 2: Per-participant shrinkage and arm selection
for (int i = 0; i < n; ++i) {
    Vec m_eb(2), v_eb(2);
    for (int a = 0; a < 2; ++a) {
        // lambda -> 1: rely on individual estimate (low noise, high heterogeneity)
        // lambda -> 0: rely on population mean   (high noise, low heterogeneity)
        double lam = (tau2_hat[a] > 0.0)
                     ? tau2_hat[a] / (tau2_hat[a] + v[i][a]) : 0.0;
        m_eb[a] = lam * m[i][a] + (1.0 - lam) * mu_hat[a];
        v_eb[a] = (tau2_hat[a] > 0.0)
                  ? (v[i][a] * tau2_hat[a]) / (v[i][a] + tau2_hat[a]) : 0.0;
    }

    // Select arm probabilistically: since both posteriors are Gaussian
    double diff     = m_eb[1] - m_eb[0];
    double var_diff = v_eb[1] + v_eb[0];
    double z        = diff / std::sqrt(std::max(var_diff, 1e-20));
    double p1       = normal_cdf(z);

    // a_{i,t} = 1 with prob P(theta_{i,1} > theta_{i,0}), else 0
    std::uniform_real_distribution<double> ud(0.0, 1.0);
    int a_sel = (ud(rng) < p1) ? 1 : 0;
}
\end{lstlisting}

\subsubsectiontitle{Notation} 

In this section specifically, $\mu_2$ is the difference between the true means of the two arms when the first arm's true mean is equal to 0. $\tau$ is the population-level standard deviation, while $\sigma$ denotes within participant noise, which is constant across all participants. $T$ is the number of time points, and $n$ is the number of participants. $\mu_0$ and $\tau_0$ are vectors of length 2, denoting the priors for the population-level distribution for the two arms respectively. All of these values are manually determined beforehand.

Furthermore, recall that for EB, the posterior mean is $m_{i,a,t} = \lambda_{i,a,t} \hat{\theta}_{i,a,t} + (1-\lambda_{i,a,t})\hat{\mu}_a$, posterior variance is $(f(a)^T \Sigma_{i,t}f(a)^{-1} + \hat{\tau}_a^{-2})^{-1}$, and shrinkage weight is $\lambda_{i,a,t} = \hat{\tau}_a^2 / (\hat{\tau}_a^2 + f(a)^T \Sigma_{i,t}f(a)).$

\sectiontitle{Contextual Bandit}
\label{sec:context-var}

\nys{This section below describes the same setting as the first section of \texttt{write-up.tex} in the \texttt{Nora/contextual bandit} folder in this same document; please refer to that document instead for the more up-to-date version.} 

The contextual bandit setting differs from the vanilla MAB setting by the presence of a context variable, $c_{i,t}$, which influences the reward distribution. Specifically, this is a linear contextual bandit setting. 

\subsectiontitle{True Environment}

The reward is now influenced by a Bernoulli context variable, which varies by $i$ (participant) and by $t$ (time): $c_{i,t} \in \{0,1\}$ where $c_{i,t} \sim \text{Bern}(0.2)$. For example, $c_{i,t}$ could represent whether the person is feeling sick or healthy (or another factor relevant to the problem that may be modeled using a binary and may vary by time point and individual). The reward is generated as
$$R_{i,t}(a) = \boldsymbol{\theta}_{i,a}^\top \boldsymbol{x}_{i,t} + \varepsilon_{i,t,a}=\theta_{i,a,0}+\theta_{i,a,1}c_{i,t}+\varepsilon_{i,t,a}$$
where $\boldsymbol{x}_{i,t} = (1, c_{i,t})^\top$, $\boldsymbol{\theta_{i,a}} = (\theta_{i,a,0}, \theta_{i,a,1})^\top$, and participant-level noise is distributed as $\varepsilon_{i,t,a} \sim \mathcal{N}(0,\sigma_a^2)$. Note that $\theta_{i,a,0}$ corresponds to the mean of a participant's reward distribution at times $t$ when $c_{i,t}=0$, and $\theta_{i,a,0}+\theta_{i,a,1}$ corresponds to the mean at times $t$ when $c_{i,t}=1$.

Furthermore, each participant's parameters are drawn from a population-level hyperdistribution: $$\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)\text{, where }\boldsymbol{\mu}_a =
\begin{pmatrix}
\mu_{a,0} \\
\mu_{a,1}
\end{pmatrix} \text{ and } \boldsymbol{\Sigma}_a
=
\begin{pmatrix}
\tau_{a,00}^2 & \tau_{a,01} \\
\tau_{a,10} & \tau_{a,11}^2
\end{pmatrix}$$

\textit{Note.} The simulations for this environment have not yet been written; however, if a simulation were being performed, $\boldsymbol{\mu}_a$, and $\boldsymbol{\Sigma}_a$ will be determined beforehand. Then, the $\theta_{i,a}^\top$ will be drawn from this manually prespecified hyperdistribution. Individual-level noise $\sigma^2_{a}$ will also be manually specified in the environment beforehand. 

\subsectiontitle{Learning Algorithm}

At each time point, the learning algorithm will observe all of a participant's rewards up to time $t$ as well as the value of the participant's $c_{i,t}$ at each time point. The learning algorithm will use ridge regression to learn the coefficient vector for each participant with $\lambda=10^{-6}$. Inclusion of a regularization term guarantees matrix invertibility.

Recall that $n_{i,a,t}$ is used to designate the number of times participant $i$ has selected action $a$ by time point $t$; the index $j=1, 2, \hdots, n_{i,a,t}$, designating the 1st time that participant chose action $a$, the 2nd time, the 3rd time, etc.
\[
\hat{\boldsymbol{\theta}}_{i,a,t}
=
\left(
\lambda I +
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
\left(
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j} r_{i,a,j}
\right)
\]

Idealistically, the learning algorithm's measure of uncertainty for each participant would be determined as follows:
\[
\boldsymbol{\Sigma}_{i,a,t}
=
\sigma_a^2
\left(
\lambda I +
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
\]

Above, uncertainty is a function of random noise associated with the observed reward output, which differs by arm ($\sigma^2_a$). However, as with the learning algorithm for the vanilla MAB that is described in Section~\ref{sec:learning}, the learning algorithm has no way of knowing $\sigma^2_a$. Thus, we estimate it using the residual variance as follows:
\begin{align*}
\hat{\sigma}_{a}^2
&=
\frac{
\sum_{i=1}^n \sum_{j=1}^{n_{i,a,t}}
\left(
r_{i,a,j} - \boldsymbol{x}_{i,j}^\top \hat{\beta}_{i,a,t}
\right)^2
}{
\sum_{i=1}^n (n_{i,a,t}-2)
}\\
\boldsymbol{\Sigma}_{i,a,t}
&=
\hat{\sigma}_{a}^2
\left(
\lambda I + \sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
\end{align*}
The second term includes the inverse Gram matrix; the Gram matrix can be thought of as measuring the amount of information (counted as number of observations) we have under different contexts, with a larger Gram matrix resulting in a smaller inverse and therefore smaller measure of uncertainty.

At each time point, the learning algorithm will send $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ to the action selection strategy.

\subsectiontitle{Action Selection Strategy}

For every combination of participant $i$ and action $a$, the EB action selection strategy receives $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ from the learning algorithm. The action selection strategy believes that $\hat{\boldsymbol{\theta}}_{i,a,t}$ are an estimate of the true means of the parameters for each participant, which are distributed around the true mean:
$$\hat{\boldsymbol{\theta}}_{i,a,t} \mid \boldsymbol{\theta}_{i,a}
\sim
\mathcal{N}(\boldsymbol{\theta}_{i,a}, \boldsymbol{\Sigma}_{i,a,t})$$

Also, EB believes that all parameters are drawn from an underlying population hyperdistribution $\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)$. Therefore, the true marginal distribution of these estimates are $\hat{\boldsymbol{\theta}}_{i,a,t}
\sim
\mathcal{N}(\boldsymbol{\mu}_a,\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})$. This parallels the vanilla MAB EB action selection strategy—$\boldsymbol{\Sigma}_a$ is the equivalent of $\tau^2_{a}$ (population-level variation) and $\boldsymbol{\Sigma}_{i,a,t}$ is the equivalent of $\sigma_{i,a}^2$ (individual-level noise).

EB's prior estimates for the hyperdistribution at time point $t$ are designated as $\boldsymbol{\theta}_{i,a}\sim \mathcal{N}(\hat{\boldsymbol{\mu}}_a,\boldsymbol{\hat{\Sigma}}_a)$. To update its estimates for the hyperdistribution, we will follow a procedure parallel to empirical Bayes as described in Section~\ref{EB}, except with vector parameters. First, we will maximize $p(\hat{\boldsymbol{\theta}}_{i,a,t} \mid \boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)$ under the new observations of $\hat{\boldsymbol{\theta}}_{i,a,t}$.
$$\ell(\boldsymbol{\mu}_a,\boldsymbol{\Sigma}_a)
=
-\frac12
\sum_{i=1}^n
\left[
2\log(2\pi)
+
\log\det(\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})
+
(\hat{\boldsymbol{\theta}}_{i,a,t}-\boldsymbol{\mu}_a)^\top
(\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
(\hat{\boldsymbol{\theta}}_{i,a,t}-\boldsymbol{\mu}_a)
\right]$$
We will use profile log-likelihood to determine hyperparameter estimates
$(\hat{\boldsymbol{\mu}}_a, \hat{\boldsymbol{\Sigma}}_a)
=
\arg\max_{\boldsymbol{\mu}_a,\,\boldsymbol{\Sigma}_a}
\;\ell(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)$:
\[
\hat{\boldsymbol{\Sigma}}_a
=
\arg\max_{\boldsymbol{\Sigma}_a \succeq 0}
\ell_p(\boldsymbol{\Sigma}_a), \quad \hat{\boldsymbol{\mu}}_a
=
\left(
\sum_{i=1}^n
(\hat{\boldsymbol{\Sigma}}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
\right)^{-1}
\left(
\sum_{i=1}^n
(\hat{\boldsymbol{\Sigma}}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
\hat{\boldsymbol{\theta}}_{i,a,t}
\right)
\]
Given these estimates, EB believes the posterior distribution of $\boldsymbol{\theta}_{i,a}$ to be:
$$\boldsymbol{\theta}_{i,a}\mid \hat{\boldsymbol{\theta}}_{i,a,t}
\sim
\mathcal{N}\left(
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}
\right)^{-1}
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}\hat{\boldsymbol{\mu}}_a
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}\hat{\boldsymbol{\theta}}_{i,a,t}
\right),
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}
\right)^{-1}
\right)$$

Finally, EB will calculate the posterior probability of one arm yielding the greater reward:
$$\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right)
=
\Phi\!\left(
\frac{
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}
\right)^{-1}
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}\hat{\boldsymbol{\mu}}_1
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}\hat{\boldsymbol{\theta}}_{i,1,t}
\right)
-
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}
\right)^{-1}
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}\hat{\boldsymbol{\mu}}_0
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}\hat{\boldsymbol{\theta}}_{i,0,t}
\right)
}{
\sqrt{
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}
\right)^{-1}
\boldsymbol{x}_{i,t}
+
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}
\right)^{-1}
\boldsymbol{x}_{i,t}
}
}
\right)$$
and an action will be selected following the same procedure as in the vanilla MAB:
$$a_{i,t}^* =
\begin{cases}
1, & \text{with probability }
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right) \\[0em]
0, & \text{with probability }
1-
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right)
\end{cases}$$
\sectiontitle{Conclusion}
In this write-up, we explored a variety of vanilla MAB and contextual MAB scenarios. For vanilla MABs, simulations were also performed. In many scenarios, EB performs best in moderate conditions, whereas pooled and unpooled TS reflect two extremes. However, there are certain scenarios, such as the misspecified prior variances described in Section~\ref{mis_var}, EB's weaknesses may be exploited. Overall, however, our findings suggest that EB offers a compromise between completely unpooled and complete pooled algorithms—a \enquote{Goldilocks} method that balances the bias-variance trade-off.

Next, we plan to test the algorithms in more complex environments that include a context variable. Specifically, we plan to test in environments with a context variables that varies by individual but not time (e.g. demographics), varies by time but not individual (e.g. weather in trials without staggered enrollment), and varies by both time and individual (Section~\ref{sec:context-var}).
