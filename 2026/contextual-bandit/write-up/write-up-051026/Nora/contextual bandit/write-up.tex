\sectiontitle{Participant-Specific and Time-Variant Context}
\label{sec:context-var}

In this report, we introduce a context variable the impacts, which participant's response to actions selected for it by the reinforcement learning algorithm. 

Specifically, we suppose that $c_{i,t}$ describes whether each individual is sick or healthy and varies by both time $t$ and participant $i$. For example, $c_{i,t}$ could represent \textit{whether the person is feeling sick or healthy}, or another factor relevant to the problem that may be modeled using a binary and may vary by time point and individual.

\subsectiontitle{True Environment}

 The reward is influenced by a Bernoulli context variable, which varies by $i$ (participant) and by $t$ (time): $c_{i,t} \in \{0,1\}$ where $c_{i,t} \sim \text{Bern}(0.2)$. The reward is generated as
$$R_{i,t}(a) = \boldsymbol{\theta}_{i,a}^\top \boldsymbol{x}_{i,t} + \varepsilon_{i,t,a}=\theta_{i,a,0}+\theta_{i,a,1}c_{i,t}+\varepsilon_{i,t,a}$$
where $\boldsymbol{x}_{i,t} = (1, c_{i,t})^\top$, $\boldsymbol{\theta_{i,a}} = (\theta_{i,a,0}, \theta_{i,a,1})^\top$, and participant-level noise is distributed as $\varepsilon_{i,t,a} \sim \mathcal{N}(0,\sigma_a^2)$.  The   $\{\varepsilon_{i,t,a} \}_{i\in [n], t\in[T], a\in \{0,1\}} $ are independent. Note that $\theta_{i,a,0}$ corresponds to the mean of a participant's reward distribution at times $t$ when $c_{i,t}=0$, and $\theta_{i,a,0}+\theta_{i,a,1}$ corresponds to the mean at times $t$ when $c_{i,t}=1$.

Furthermore, each participant's parameters are drawn from a population-level hyperdistribution: $$\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)\text{, where }\boldsymbol{\mu}_a =
\begin{pmatrix}
\mu_{a,0} \\
\mu_{a,1}
\end{pmatrix} \text{ and } \boldsymbol{\Sigma}_a
=
\begin{pmatrix}
\tau_{a,00}^2 & \tau_{a,01} \\
\tau_{a,10} & \tau_{a,11}^2
\end{pmatrix}$$

The $\{\theta_{i,a}\}_{i\in[n],a\in \{0,1\}} $ are independent.  \sam{Note that $\tau_{a,01} =
\tau_{a,10}$.}

\subsectiontitle{Learning Algorithm}
\label{learning-alg-unpooled}

\textit{The learning algorithm does not have knowledge of the above environment.} The learning algorithm believes that rewards are generated using the following model:
$$R_{i,t}(a) = \boldsymbol{\theta}_{i,a}^\top \boldsymbol{x}_{i,t} + \varepsilon_{i,t,a}=\theta_{i,a,0}+\theta_{i,a,1}c_{i,t}+\varepsilon_{i,t}$$
where $\boldsymbol{x}_{i,t} = (1, c_{i,t})^\top$, $\boldsymbol{\theta_{i,a}} = (\theta_{i,a,0}, \theta_{i,a,1})^\top$, and participant-level noise is distributed as $\varepsilon_{i,t} \sim \mathcal{N}(0,\sigma_a^2)$.  The   $\{\varepsilon_{i,t} \}_{i\in [n], t\in[T]} $ are assumed independent. (While the learning algorithm's model happens to align with the true underlying environment in this case, this alignment is not guaranteed.) \sam{Usually you would use different greek letters for the learning algorithm's model so that the reader does not think that the learning algorithm has access to the environment's model.  Note here the learning algorithm and the environment are using the same model but that does not  happen in real life.  All learning algorithms approximate the real life environment in some way.}


The learning algorithm, which will be paired with empirical Bayes and unpooled contextual Thompson Sampling action selection strategies, is performed individually on each participant's data. When producing estimates for individual $i$, it only sees individual $i$'s data and no other participant's. For the pooled learning algorithm for pooled Thompson sampling, please see Section~\ref{pooled-learning}.

At each time point, the learning algorithm will observe all of a participant's $(r_{i,a=a_{i,j}, j}, c_{i,j})$ up to time $j<t$ 
%\sam{ $r_{i,a=a_{i,j}, j}, c_{i,j}$'s up to time $j<t$} \nys{Added!} 
as well as the value of the participant's $c_{i,t}$ at each time point. The learning algorithm will use ridge regression to learn the coefficient vector for each participant with $\lambda=10^{-6}$. The learning algorithm separately estimates the bivariate vector $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ for $a=0$ and $a=1$ separately, assuming the parameters for the two actions for each participant are independent.  %\sam{what is \enquote{they} in prior sentence---participants?} \nys{\enquote{They} are $\boldsymbol{\Sigma}_{i,a=0,t}$ and $\boldsymbol{\Sigma}_{i,a=1,t}$.}

%\nys{I have revised this section to specify the ridge regression prior.} 
We can interpret the ridge regression through a Bayesian lens. Before any learning occurs, the prior used by the ridge regression is
$$\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(0, \tau_{0,a}^2 I), \quad \lambda = \frac{\sigma_a^2}{\tau_{0,a}^2}
=10^{-6}$$
where $\lambda$ represents the signal to noise ratio, which we set very close to 0; this minimizes the weight given to our prior, making us rely mostly on our estimate. From the Bayesian perspective, the prior variance $\tau^2_{0,a}=\lambda \sigma_{a}^2$. In other words, the prior variance is $10^{-6}$ times the unknown $\sigma_a^2$. 
%\sam{This Bayesian perspective, with $\lambda = 10^{-6}$ implies that you are selecting the prior variance, $\tau_0^2$ to be equal to  $10^{6}$ times the unknown $\sigma_a^2$.  That is,  in fact, $\tau_0^2$ is $\tau_{0,a}^2$. } \nys{Corrected and clarified!}
%\nys{Clarify it's not indexed by $i$ but can be.} 
Above, we decided not to index parameters like $\lambda$ by $i$, meaning our prior does not differ by individual. However, if we so choose, we can vary $\lambda$ by $i$, tuning this hyperparameter.

Then, the learning algorithm's uncertainty about its estimates can be described as follows: 
\[
\boldsymbol{\Sigma}_{i,a,t}
=
\left(
\frac{1}{\tau_0^2} I
+
\frac{1}{\sigma_{i,a}^2}
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
=
\sigma_{i,a}^2
\left(
\frac{\sigma_{i,a}^2}{\tau_0^2} I
+
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
=
\sigma_{i,a}^2
\left(
\lambda I
+
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}.
\]
where $\boldsymbol{x}_{i,j} = (1, c_{i,j})^\top$ and $n_{i,a,t}$ is the number of times the algorithm has selected action $a$ for participant $i$ up to time $t$.  
%\sam{participants do not select the actions.....} \nys{Corrected!}

From these expressions, we can see that adding $\lambda I$ in ridge regression ensures invertibility early on during the trial, when the participant may not have pulled an arm more than twice.

The learning algorithm must also produce the estimate that the measure of uncertainty describes. Recall that $n_{i,a,t}$ is used to designate the number of times participant $i$ has selected action $a$ by time point $t$; the index $j=1, 2, \hdots, n_{i,a,t}$, designating the 1st time that participant chose action $a$, the 2nd time, the 3rd time, etc. We use ridge regression to separately estimate each coefficient as follows: 
\[
\hat{\boldsymbol{\theta}}_{i,a,t}
=
\left(
\lambda I +
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}
\left(
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j} r_{i,a,j}
\right)
\]

%\nys{I have corrected the residual variance to avoid pooling over participants.} 
After obtaining the estimate, the learning algorithm will use the equation for $\boldsymbol{\Sigma}_{i,a,t}$ that we specified above to determine its measure of uncertainty for each estimate, approximating the true noise with the residual variance:
\[
\boldsymbol{\Sigma}_{i,a,t}
=
\hat{\sigma}_{i,a,t}^2
\left(
\lambda I
+
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^\top
\right)^{-1}, \quad \hat{\sigma}_{i,a,t}^2
=
\frac{
\sum_{j=1}^{n_{i,a,t}}
\left(
r_{i,a,j}
-
\boldsymbol{x}_{i,j}^\top \hat{\boldsymbol{\theta}}_{i,a,t}
\right)^2
}{
n_{i,a,t}-2
}
\]

At each time point, the learning algorithm will send bivariate vector $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ to the action selection strategy. 
%\nys{I have added this section to clarify that we are sending four parameter estimates per individual.} 
The learning algorithm sends a separate set of $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ for $a=0$ and $a=1$; thus, it actually sends four coefficient estimates per individual. The current learning algorithm independently estimates $\boldsymbol{\Sigma}_{i,a,t}$ for $a=0$ and $a=1$.
\label{ridge-alg}
\begin{codechunk}{Ridge Regression}
// in practice, the learning alg maintains sufficient stats
struct RidgeState {
    M2 XtX;  // sum x x^T
    Vec Xty; // sum x*r
    Vec r_hist;
    std::vector<Vec> x_hist;
    int n_obs; // number of observations 
};

// at t = 0: X^T X = 0, X^T y = 0, and n_{i,a,t} = 0
inline void init_state(RidgeState& s) {
    s.XtX = {0,0,0,0};
    s.Xty = {0.0,0.0};
    s.n_obs = 0;
}

// after observing a new data point (x, r), update the running sums:
// X^T X <- X^T X + x x^T
// X^T y <- X^T y + x r
inline void update_state(RidgeState& s, const Vec& x, double r) {
    s.XtX.a += x[0]*x[0]; s.XtX.b += x[0]*x[1];
    s.XtX.c += x[1]*x[0]; s.XtX.d += x[1]*x[1];
    s.Xty[0] += x[0]*r;   s.Xty[1] += x[1]*r;
    s.x_hist.push_back(x);
    s.r_hist.push_back(r);
    s.n_obs++;
}

// returns (theta_hat, Sigma_hat)
inline void ridge_estimate(const RidgeState& s, double lam, const Vec& mu_prior,
                            Vec& theta_hat, M2& Sigma_hat) {
    M2 G = { s.XtX.a+lam, s.XtX.b, s.XtX.c, s.XtX.d+lam };
    M2 Ginv = inv2(G);
    theta_hat = matvec2(Ginv, s.Xty);
    // if no data yet, set as prior mean
    if (s.n_obs == 0) theta_hat = mu_prior;
    // estimate residual variance
    double sigma2 = 1.0;
    // calculates Sigma_{i,a,t} using residual variance estimate
    if (s.n_obs > 2) {
        double rss = 0.0;
        for (int j=0; j<s.n_obs; ++j) {
            double pred = s.x_hist[j][0]*theta_hat[0] + s.x_hist[j][1]*theta_hat[1];
            double e = s.r_hist[j] - pred;
            rss += e*e;
        }
        sigma2 = rss / (s.n_obs - 2);
        // sets very small values to 1e-8
        if (sigma2 < 1e-8) sigma2 = 1e-8;
    }
    Sigma_hat = scale2(Ginv, sigma2);
}

\subsubsectiontitle{Empirical Bayes}
\label{action}

%\nys{I have revised this section to better specify EB's perspective.}
At each time $t$, for every combination of participant $i$ and action $a$, the EB action selection strategy receives a set of \textit{data points}—the bivariate vector $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$—from the learning algorithm. This is the data EB will use at time $t$.

The action selection strategy believes that $\hat{\boldsymbol{\theta}}_{i,a,t}$ are an unbiased estimate of individual $i$'s coefficients (in the model specified by the learning algorithm), and they are distributed around the individual $i$'s coefficients as follows:
$$\hat{\boldsymbol{\theta}}_{i,a,t} \mid \boldsymbol{\theta}_{i,a}
\sim
\mathcal{N}(\boldsymbol{\theta}_{i,a}, \boldsymbol{\Sigma}_{i,a,t})$$
For the future it is useful to realize that  the above can be written as a \textit{multivariate} linear regression:
$$\hat{\boldsymbol{\theta}}_{i,a,t}= \boldsymbol{\theta}_{i,a} + \epsilon_{i,a}$$
where the bivariate distribution of  $\epsilon_{i,a}$ is $\mathcal{N}(\boldsymbol{0}, \boldsymbol{\Sigma}_{i,a,t})$.

Furthermore, EB believes that all the true coefficients are drawn from an underlying population hyperdistribution $\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)$ (i.e., the Bayesian aspect of EB). Thus, after being provided these estimates, the posterior distribution of the \textit{true} $\boldsymbol{\theta}_{i,a}$ must be:
$$\boldsymbol{\theta}_{i,a}\mid \hat{\boldsymbol{\theta}}_{i,a,t}
\sim
\mathcal{N}\left(
\left(
\boldsymbol{\Sigma}_a^{-1}
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}
\right)^{-1}
\left(
\boldsymbol{\Sigma}_a^{-1}\boldsymbol{\mu}_a
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}\hat{\boldsymbol{\theta}}_{i,a,t}
\right),
\left(
\boldsymbol{\Sigma}_a^{-1}
+
\boldsymbol{\Sigma}_{i,a,t}^{-1}
\right)^{-1}
\right)$$
The above can be derived using the Normal-Normal Conjugacy and only applies to Normal cases. See pages $3-4$ for a derivation.\autocite{sun_steps} In other cases, another posterior may be derived. 

%\nys{I have re-organized this section to first state the posterior distribution and then mention the empirical hyperparameter estimation.} 
In a fully Bayesian set-up, the algorithm would be aware of and use the true population hyperparameters to determine the posterior distribution of the individual means. However, in this setting, we assume that the true population hyperparameters are unknown; thus, we must \textit{empirically} estimate these hyperparameters, making this algorithm EB. 

EB's prior estimates for the population-level hyperdistribution will be designated as $\mathcal{N}(\hat{\boldsymbol{\mu}}_a,\boldsymbol{\hat{\Sigma}}_a)$. In this scenario, 
%EB believes that 
the marginal distribution of the data is $\hat{\boldsymbol{\theta}}_{i,a,t}
\sim
\mathcal{N}(\boldsymbol{\mu}_a,\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})$, where we have variation due to population-level heterogeneity and measurement noise, the latter of which is given to EB by the learning algorithm. This posterior derives from the fact that we have two \textit{independent} and Normally distributed sources of error in the model: 
\begin{align*}
\text{Individual-level noise} \sim \mathcal{N}(0,\boldsymbol{\Sigma}_{i,a,t})\\
\text{Population heterogeneity} \sim \mathcal{N}(0,\boldsymbol{\Sigma}_a)
\end{align*}
The former is measurement error, while the latter is true variability; collectively, they explain all variation in the estimates produced by the learning algorithm.  %\sam{very nice...}
$$\hat{\boldsymbol{\theta}}_{i,a,t} = \boldsymbol{\mu}_a + \left(\boldsymbol{\theta}_{i,a} - \boldsymbol{\mu}_a\right) + \left(\hat{\boldsymbol{\theta}}_{i,a,t} - \boldsymbol{\theta}_{i,a}\right), \quad \mathrm{Var}(\hat{\boldsymbol{\theta}}_{i,a,t}) = \mathrm{Var}(\boldsymbol{\delta}_i) + \mathrm{Var}(\mathbf{e}_i) = \boldsymbol{\Sigma}_a + \boldsymbol{\Sigma}_{i,a,t}$$
For a full derivation of this marginal distribution, please see equation 8 (p. 78) and equation 18 (p. 80) \autocite{doi:10.3102/10769986010002075}. The marginalization process is shown in more detail in Section~\ref{action2}. Again, note that the marginal distribution may differ in other settings. 

Using this marginal distribution, EB can estimate the hyperdistribution by maximizing $p(\hat{\boldsymbol{\theta}}_{i,a,t} \mid \boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})$, which is the likelihood of observing the data given by the learning algorithm, $\hat{\boldsymbol{\theta}}_{i,a,t}$. %\nys{Specifying how we assume independent parameters under each action.} 
Again, please recall that as we assume the hyperparameters and parameters beneath $a=1$ and $a=0$ are independent, our likelihood only sums over individuals $i$ and not action $a$. 
$$\ell(\boldsymbol{\mu}_a,\boldsymbol{\Sigma}_a)
=
-\frac12
\sum_{i=1}^n
\left[
2\log(2\pi)
+
\log\det(\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})
+
(\hat{\boldsymbol{\theta}}_{i,a,t}-\boldsymbol{\mu}_a)^\top
(\boldsymbol{\Sigma}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
(\hat{\boldsymbol{\theta}}_{i,a,t}-\boldsymbol{\mu}_a)
\right].$$
Then, we use profile log-likelihood to determine hyperparameter estimates
$(\hat{\boldsymbol{\mu}}_a, \hat{\boldsymbol{\Sigma}}_a)
=
\arg\max_{\boldsymbol{\mu}_a,\,\boldsymbol{\Sigma}_a}
\;\ell(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a)$:
\[
\hat{\boldsymbol{\Sigma}}_a
=
\arg\max_{\boldsymbol{\Sigma}_a \succeq 0}
\ell_p(\boldsymbol{\Sigma}_a), \quad \hat{\boldsymbol{\mu}}_a
=
\left(
\sum_{i=1}^n
(\hat{\boldsymbol{\Sigma}}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
\right)^{-1}
\left(
\sum_{i=1}^n
(\hat{\boldsymbol{\Sigma}}_a+\boldsymbol{\Sigma}_{i,a,t})^{-1}
\hat{\boldsymbol{\theta}}_{i,a,t}
\right)
\]
\label{decision}
%\sam{What software will you use to calculate $\hat{\boldsymbol{\Sigma}}_a$? } \nys{Since there is no closed-for solution, I use EM, warm-starting with hyperparameter estimates from previous time step $t-1$ to minimize iterations.} 
Now, EB has estimated the posterior distribution for the true individual-level parameters given the observed data, which we denoted earlier as $\boldsymbol{\theta}_{i,a}\mid \hat{\boldsymbol{\theta}}_{i,a,t}$. EB will determine the posterior probability of one arm yielding the greater reward:
$$\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right)
=
\Phi\!\left(
\frac{
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}
\right)^{-1}
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}\hat{\boldsymbol{\mu}}_1
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}\hat{\boldsymbol{\theta}}_{i,1,t}
\right)
-
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}
\right)^{-1}
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}\hat{\boldsymbol{\mu}}_0
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}\hat{\boldsymbol{\theta}}_{i,0,t}
\right)
}{
\sqrt{
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_1^{-1}
+
\boldsymbol{\Sigma}_{i,1,t}^{-1}
\right)^{-1}
\boldsymbol{x}_{i,t}
+
\boldsymbol{x}_{i,t}^\top
\left(
\boldsymbol{\hat{\Sigma}}_0^{-1}
+
\boldsymbol{\Sigma}_{i,0,t}^{-1}
\right)^{-1}
\boldsymbol{x}_{i,t}
}
}
\right)$$
and an action will be selected following the same procedure as in the vanilla MAB:
$$a_{i,t}^* =
\begin{cases}
1, & \text{with probability }
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right) \\[0em]
0, & \text{with probability }
1-
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right)
\end{cases}$$
\textit{Note:} When implementing empirical Bayes in practice, in lieu of calculating this probability, a random draw would be performed from each of the two $\boldsymbol{\theta}_{i,a}$ posterior distributions, and the action yielding the greater $\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,a}$ value will be selected. 

\begin{codechunk}{Empirical Bayes}
for (int t=0; t<T; ++t) {
    // stores theta estimates
    // INDIVIDUAL-LEVEL LEARNING:
    // run the ridge regression individually where i=specific participant
    for (int i=0; i<n; ++i) for (int a=0; a<2; ++a) {
        ridge_estimate(state[i][a], lam, mu0_prior,
                       theta_hat[i][a], Sigma_hat[i][a]);
        has_data[i][a] = state[i][a].n_obs > 0;
    }

    // HYPERPARAMETER ESTIMATION:
    // EM-style iterative update
    for (int a=0; a<2; ++a) {
        // counts number of participants 
        int nn = 0;
        for (int i=0; i<n; ++i) if (has_data[i][a]) nn++;
        if (nn==0) continue;
        // fetch prior estimates of population-level hyperparameters
        Vec mu_cur    = mu_pop[a];
        M2  Sigma_cur = Sigma_pop[a];
        // EM ALGORITHM BEGINS HERE
        // notably, we will warm start with prior hyperparameter estimate to reduce number of iterations 
        for (int iter=0; iter<MAX_ITER; ++iter) {
            // calculates posterior hyperparameters *just* from data in a given round
            Vec mu_new    = {0.0, 0.0};
            M2  Sigma_new = {0.0, 0.0, 0.0, 0.0};
            // E-STEP
            // performs updates for each individual-action (i,a) combination with data, aka computes theta_{i,a} | theta_hat_{i,a,t} 
            for (int i=0; i<n; ++i) {
                if (!has_data[i][a]) continue;
                M2  Sp_inv    = inv2(Sigma_cur);
                M2  Si_inv    = inv2(Sigma_hat[i][a]);
                M2  post_cov  = inv2(add2(Sp_inv, Si_inv));
                Vec rhs       = matvec2(Sp_inv, mu_cur);
                Vec tmp       = matvec2(Si_inv, theta_hat[i][a]);
                rhs[0]+=tmp[0]; rhs[1]+=tmp[1];
                Vec post_mean = matvec2(post_cov, rhs);
                mu_new[0] += post_mean[0];
                mu_new[1] += post_mean[1];
                Sigma_new = add2(Sigma_new, add2(post_cov, outer2(post_mean)));
            }
            // M-STEP
            // posterior mean is new mu
            mu_new[0] /= nn; mu_new[1] /= nn;
            // new Sigma = E[theta*theta^T] - mu_new*mu_new^T by def of variance
            Sigma_new = sub2(scale2(Sigma_new, 1.0/nn), outer2(mu_new));
            Sigma_new = project_psd(Sigma_new, 1e-8);
            // check for convergence 
            double delta = std::abs(mu_new[0]-mu_cur[0])
                         + std::abs(mu_new[1]-mu_cur[1])
                         + std::abs(Sigma_new.a-Sigma_cur.a)
                         + std::abs(Sigma_new.d-Sigma_cur.d);
            mu_cur = mu_new; Sigma_cur = Sigma_new;
            if (delta < TOL) break;
        }
        // save after convergence - used for warm start at next time point t
        mu_pop[a] = mu_cur; Sigma_pop[a] = Sigma_cur;
    }

    // PER PARTICIPANT ACTION SELECTION: loops through each participant
    M2 Sp_inv[2] = { inv2(Sigma_pop[0]), inv2(Sigma_pop[1]) };
    for (int i=0; i<n; ++i) {
        Vec x = {1.0, (double)env.context[i][t]};
        int a_sel;
        // if one of the two arms has never been tried, pick one randomly (forced explorer)
        if (!has_data[i][0] || !has_data[i][1]) {
            a_sel = ud(rng);
        } else {
            // COMPUTE POSTERIOR DISTRO: theta_{i,a} | theta_hat_{i,a,t}
            double reward_mean[2], reward_var[2];
            for (int a=0; a<2; ++a) {
                M2  Si_inv    = inv2(Sigma_hat[i][a]);
                M2  post_cov  = inv2(add2(Sp_inv[a], Si_inv));
                Vec rhs       = matvec2(Sp_inv[a], mu_pop[a]);
                Vec tmp       = matvec2(Si_inv, theta_hat[i][a]);
                rhs[0]+=tmp[0]; rhs[1]+=tmp[1];
                Vec post_mean = matvec2(post_cov, rhs);
                // calculate expected reward using context for participant
                reward_mean[a] = x[0]*post_mean[0]+x[1]*post_mean[1];
                reward_var[a]  = quad2(x, post_cov);
            }
            // P(x_{i,t}*theta_{i,a=a_0} > x_{i,t}*theta_{i,a=a_1})
            double diff = reward_mean[1]-reward_mean[0];
            double sd   = std::sqrt(std::max(reward_var[0]+reward_var[1], 1e-20));
            // sample and select greater expected reward
            a_sel = (ur(rng) < normal_cdf(diff/sd)) ? 1 : 0;
        }

        // TRUE ENVIRONMENT (NOT part of action selection): generate rewards, calculate regret
        double mean_r = expected_reward(env,i,t,a_sel);
        double r      = mean_r + sigma_r*nd(rng);
        update_state(state[i][a_sel], x, r);
        total_regret += best_expected(env,i,t) - mean_r;
    }
}
\end{codechunk}

Like EB, contextual unpooled Thompson sampling will also receive $(\hat{\boldsymbol{\theta}}_{i,a,t}, \boldsymbol{\Sigma}_{i,a,t})$ from the learning algorithm for each participant $i$ and arm $a$ at time $t$. In this case, the prior is the Ridge regression prior at time $0$: $$\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(0, \tau_{0,a}^2 I), \quad \lambda = \frac{\sigma_a^2}{\tau_{0,a}^2}
=10^{-6}.$$

Importantly, unpooled TS only uses the data for a given participant $i$ to determine the action for that participant; it does not consider the data observed from other participants. For each individual, Thompson sampling's  posterior distribution of their reward parameters is:
$$\boldsymbol{\theta}_{i,a,t}
\sim
\mathcal{N}\!\left(
\hat{\boldsymbol{\theta}}_{i,a,t},
\boldsymbol{\Sigma}_{i,a,t}
\right)$$

A reward is generated though a random draw of both arms, and the arm with the higher draw \textit{given} the context of that participant $i$ is selected.
$$R_{i,t}(a)
=
\boldsymbol{x}_{i,t}^{\top}\boldsymbol{\theta}_{i,a,t}, \quad a_{i,t}^{*}
=
\arg\max_{a\in\{0,1\}}
R_{i,t}(a)$$

\subsubsectiontitle{Pooled Thompson Sampling}
\label{pooled-learning}
Note that while this section is focused on the pooled Thompson sampling \textit{action selection} strategy, we first must clarify the corresponding learning algorithm that makes this action selection strategy \enquote{pooled.} 

%\sam{What model is the learning algorithm using?   } \nys{Added in first paragraph in below box!}

\begin{notebox}[Pooled Learning Algorithm]
The learning algorithm has no knowledge of the true underlying environment and instead assumes the following model for the observed rewards:
$$R_{i,t}(a) = \boldsymbol{\theta}_{i}^\top \boldsymbol{x}_{i,t} + \varepsilon_{i,t,a}=\theta_{a,0}+\theta_{a,1}c_{i,t}+\varepsilon_{i,t}$$
where $\boldsymbol{x}_{i,t} = (1, c_{i,t})^\top$, $\boldsymbol{\theta_{a}} = (\theta_{a,0}, \theta_{a,1})^\top$, and participant-level noise is distributed as $\varepsilon_{i,t} \sim \mathcal{N}(0,\sigma^2)$  where $\{\varepsilon_{i,t}\}_{i\in[n], t\in [T]}$ are i.i.d. \\

Rather than the participant-level learning algorithm described in Section~\ref{learning-alg-unpooled}, a pooled ridge regression is performed on all participants' data. The prior is as follows:

$$
\boldsymbol{\theta}_{a} \sim \mathcal{N}(0, \tau_{0,a}^2 I),
\quad
\lambda = \frac{\sigma_a^2}{\tau_{0,a}^2}=10^{-6}
$$

The estimates are yielded with the ridge regression learning algorithm as follows, using pooled data from each arm:

\[
\hat{\boldsymbol{\theta}}_{a,t}
=
\left(
\lambda I
+
\sum_{i=1}^{n}\sum_{j=1}^{n_{i,a,t}}
\boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^{\top}
\right)^{-1}
\left(
\sum_{i=1}^{n}\sum_{j=1}^{n_{i,a,t}}
\boldsymbol{x}_{i,j}r_{i,a,j}
\right)
\]
 where $\boldsymbol{x}_{i,j} = (1, c_{i,j})^\top$ and $n_{i,a,t}$ is the number of times the algorithm has selected action $a$ for participant $i$ up to time $t$. Then, the learning algorithm's residuals and uncertainty is pooled \textit{across} individuals:
\[
\boldsymbol{\Sigma}_{a,t}
=
\hat{\sigma}_{a,t}^2
\left(
\lambda I
+
\sum_{i=1}^{n}\sum_{j=1}^{n_{i,a,t}}
\boldsymbol{x}_{i,j}\boldsymbol{x}_{i,j}^{\top}
\right)^{-1},
\quad
\hat{\sigma}_{a,t}^2
=
\frac{
\sum_{i=1}^{n}\sum_{j=1}^{n_{i,a,t}}
\left(
r_{i,a,j}
-
\boldsymbol{x}_{i,j}^{\top}\hat{\boldsymbol{\theta}}_{a,t}
\right)^2
}{
\sum_{i=1}^{n} n_{i,a,t} - 2
}
\]

To achieve this, we still use the \texttt{ridge\_estimate()} function written in Algorithm~\protect\ref{ridge-alg}, but we call it on \texttt{state[a]} instead of \texttt{state[i][a]} as shown in Algorithm~\ref{ridge-alg-pooled} below.

\end{notebox}

This action selection strategy believes that the true $\boldsymbol{\theta}_{a}$ parameters are constant across the population with posterior distribution:  
$$
\boldsymbol{\theta}_{a}
\sim
\mathcal{N}\!\left(
\hat{\boldsymbol{\theta}}_{a,t},
\boldsymbol{\Sigma}_{a,t}
\right)
$$

Again, a reward is generated though a random draw of $\boldsymbol{\theta}_{a}$ for both arms, from their posterior distributions.  The arm with the higher draw \textit{given} the context of that participant $i$ is selected. Draws will be performed independently for each of the $n$ participants to select an action for each individual, even though these draws will all be from the same pooled distribution. 
$$
R_{i,t}(a)
=
\boldsymbol{x}_{i,t}^{\top}\boldsymbol{\theta}_{a},
\quad
a^*_{i,t}
=
\arg\max_{a \in \{0,1\}}
R_{i,t}(a)
$$ \label{ridge-alg-pooled}
\begin{codechunk}{Pooled Thompson Sampling}
for (int t=0; t<T; ++t) {
    // shared posterior
    // we do NOT loop through individuals here unlike for unpooled TS 
    Vec theta_hat[2]; M2 Sigma_hat[2];
    bool ready[2];
    for (int a=0; a<2; ++a) {
        // again, we are running ridge regression on data from ALL participants
        ridge_estimate(state[a], lam, mu0_prior, theta_hat[a], Sigma_hat[a]);
        ready[a] = state[a].n_obs > 0;
    }
    // *now* we loop through individuals for action selection 
    for (int i=0; i<n; ++i) {
        Vec x = {1.0, (double)env.context[i][t]};
        int a_sel;
        // if one of the two arms has never been tried, pick one randomly (forced explorer)
        if (!ready[0] || !ready[1]) {
            a_sel = ud(rng);
        } else {
            double samp_reward[2];
            for (int a=0; a<2; ++a) {
                // sample and calculate reward for each arm
                Vec th_draw = sample_mvn2(theta_hat[a], Sigma_hat[a], rng);
                samp_reward[a] = x[0]*th_draw[0]+x[1]*th_draw[1];
            }
            // select the action with the higher expected reward given the context 
            a_sel = (samp_reward[1] > samp_reward[0]) ? 1 : 0;
        }
        // get true expected reward
        double mean_r = expected_reward(env,i,t,a_sel);
        // random draw  
        double r      = mean_r + sigma_r*nd(rng);
        // save new data point 
        update_state(state[a_sel], x, r);
        // calculate regret = best possible reward - reward of selected action (true means)
        total_regret += best_expected(env,i,t) - mean_r;
    }
}

\subsectiontitle{Simulations}
\label{time-var-sim}

In the below simulations, we explore the performance of the three action selection strategies for varying context prevalence (i.e., $P(c_{i,t}=1)$, or how rare one context is compared to the other). Simulations include $9$ evenly spaced values of $p$ between $0.1$ and $0.5$. $P(c_{i,t}=1)=0.1$ implies that there is a paucity of data for one context (e.g., participants are rarely sick; they are only sick $10\%$ of the time), whereas $P(c_{i,t}=1)=0.5$ implies that we have similar information about both contexts. Sweeping through these values of $P(c_{i,t}=1)$, we test several meaningful conjectures:

\textit{First}, we conjecture that when the optimal arm differ by context, and sample size ($n=50$) and time points ($T=100$) are sufficient: At high heterogeneity-to-noise ratios (i.e. $\tau^2_{1,11}+\tau^2_{0,11}$ are large relative to $\sigma^2$), unpooled TS performs the best; at low heterogeneity-to-noise ratios, pooled TS performs best; at middling ratios, EB performs best. Our simulations indeed confirmed that this is the case.\autocite{sun_kreiman_2026_slides} \nys{You asked not to see these specific graphs again, since they're what we expected; just wanted to note somewhere in the write-up that we did check this.}

Realistically, we expect to deal with environments where the heterogeneity-to-noise ratio is relatively low (i.e., \enquote{difficult} environments where participant responses are not clearly different). After establishing the first conjecture to be true, the rest of our simulations will be run in moderate heterogeneity-to-noise environments, where we will test the effect of data paucity on algorithm performance through altering $T$ and $n$:

\nys{Nora's graph on slide 6.} \textit{Second}, we test the effect of varying the number of time points $T$ on algorithm performance. The primary difference between EB and pooling algorithms, the top two contenders in moderate-to-low heterogeneity-to-noise settings, is that pooling algorithm pools during learning, while EB only pools during action selection. Thus, we expect EB to perform worse than pooled at low values of $T$. However, we expect this disadvantage to be overcome once the participants are heterogeneous enough to warrant not pooling during learning, so EB should improve. \nys{We also tested changing $n$, but the results were expected, so you asked us to exclude that graph.}

\btk{Betina's graph on Slide 7.} \textit{Third,} we test a setting where the context is present but does not change which arm is optimal. The context shifts rewards for both arms equally, so arm $1$ remains universally better, regardless of $c_i$. This setting is motivated by understanding what happens when algorithms that model context are deployed in an environment where context provides no useful information about arm selection. This is meaningfully different from a similarly low-heterogeneity setting where arms are opposite by context. There, context is genuinely informative and algorithms that leverage it are rewarded for doing so. Here, modeling context is unnecessary and potentially costly, since it introduces estimation without any benefit to arm selection. In particular, we expect EB's performance relative to pooled TS to be largely unaffected by sweeping $p$. This is because the optimal action does not depend on context, so varying the proportion of $c_i=1$ for participants provides no new signal for arm selection. \begin{codechunk} {Scalar Learning Algorithm}
// Since c_i is fixed, each participant observes only one context value.
// The learning algorithm therefore fits a scalar model per (participant, arm):
//   R_{i,t}(a) = theta^L_{i,a} + noise,   theta^L_{i,a} = x_i^T theta_{i,a}
// and outputs scalar estimate theta_hat^L and uncertainty Sigma^L.

struct ScalarState {
    double sum_r;   // sum of rewards observed for this (participant, arm)
    double sum_r2;  // sum of squared rewards (for residual variance)
    int    n_obs;
};

inline void init_scalar(ScalarState& s){ s.sum_r=0; s.sum_r2=0; s.n_obs=0; }
inline void update_scalar(ScalarState& s, double r){
    s.sum_r+=r; s.sum_r2+=r*r; s.n_obs++;
}

// theta_hat^L = (lam + n)^{-1} * sum_r
// Sigma^L     = sigma2_hat * (lam + n)^{-1},   sigma2_hat via (n-1) denominator
inline void scalar_estimate(const ScalarState& s, double lam,
                             double& th, double& sig) {
    double denom = lam + s.n_obs;
    th = (s.n_obs > 0) ? s.sum_r / denom : 0.0;
    double sigma2 = 1.0;
    if (s.n_obs > 1) {
        double rss = s.sum_r2 - 2.0*th*s.sum_r + (double)s.n_obs*th*th;
        sigma2 = std::max(rss / (s.n_obs - 1), 1e-8);
    }
    sig = sigma2 / denom;
}
\end{codechunk}

    \hat{\tau}_{a,00}^2 &= \frac{1}{n_0 - 1}\sum_{i: c_i=0}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{0,a,t}\right)^2 - \overline{\Sigma}^L_{0,a,t}\\
    \hat{\tau}_{a,11}^2 &= \frac{1}{n_1 - 1}\sum_{i: c_i=1}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{1,a,t}\right)^2 - \overline{\Sigma}^L_{1,a,t} - \hat{\tau}_{a,00}^2
\end{align*}
Then, we actually do use the closed-form MLE equation to calculate the MLE for $\hat{\boldsymbol{\mu}}_a$. 

Now, using these hyperparameter estimates, the  posterior distribution $\boldsymbol{\theta}_{i,a}
\mid
\hat{\theta}^{L}_{i,a,t}$ is empirically approximated as:
$$\boldsymbol{\theta}_{i,a}
\mid
\hat{\theta}^{L}_{i,a,t}
\sim
\mathcal{N}
\left(
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}
+
\frac{1}{\Sigma^{L}_{i,a,t}}
\boldsymbol{x}_i\boldsymbol{x}_i^\top
\right)^{-1}
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}\hat{\boldsymbol{\mu}}_a
+
\frac{1}{\Sigma^{L}_{i,a,t}}
\boldsymbol{x}_i \hat{\theta}^{L}_{i,a,t}
\right),
\left(
\hat{\boldsymbol{\Sigma}}_a^{-1}
+
\frac{1}{\Sigma^{L}_{i,a,t}}
\boldsymbol{x}_i\boldsymbol{x}_i^\top
\right)^{-1}
\right)$$

Finally, EB can similarly use the sampling approach described in Section \ref{action} to select an action for each individual.
$$a_{i,t}^* =
\begin{cases}
1, & \text{with probability }
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right) \\[0em]
0, & \text{with probability }
1-
\textrm{P}\!\left(
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,1}
>
\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,0}
\right)
\end{cases}$$
\textit{Note:} When implementing empirical Bayes in practice, in lieu of calculating this probability, a random draw would be performed from each of the two $\boldsymbol{\theta}_{i,a}$ distributions, and the action yielding the greater $\boldsymbol{x}_{i,t}^\top \boldsymbol{\theta}_{i,a}$ value will be selected.

for (int t=0; t<T; ++t) {

    // --- Step 1: update individual scalar estimates ---
    // KEY DIFFERENCE: scalar estimates instead of 2D ridge estimates —
    // c_i is fixed so only one context is ever observed per participant
    for (int i=0; i<n; ++i) for (int a=0; a<2; ++a) {
        scalar_estimate(state[i][a], lam, theta_hat[i][a], sigma_hat[i][a]);
        has_data[i][a] = state[i][a].n_obs > 0;
    }

    // --- Step 2: MOM hyperparameter estimation per arm ---
    // KEY DIFFERENCE: MOM uses two context groups instead of EM —
    // since c_i is fixed, we can only identify two variance equations
    // (one per context group), so Sigma_pop is constrained to be diagonal
    for (int a=0; a<2; ++a) {
        // split participants into c_i=0 and c_i=1 groups
        std::vector<int> grp0, grp1;
        for (int i=0; i<n; ++i) {
            if (!has_data[i][a]) continue;
            (env.context[i]==0 ? grp0 : grp1).push_back(i);
        }
        int n0=grp0.size(), n1=grp1.size();

        // MOM for tau2_{a,00} from c_i=0 group:
        // Var(theta_hat^L | c=0) = tau2_00 + mean(Sigma^L),  x_i=(1,0)
        // so tau2_00 = sample_var(theta_hat^L in c=0 group) - mean(Sigma^L)
        double tau2_00 = 0.0;
        if (n0 > 1) {
            double m0=0; for (int i:grp0) m0+=theta_hat[i][a]; m0/=n0;
            double v0=0; for (int i:grp0){double d=theta_hat[i][a]-m0; v0+=d*d;} v0/=(n0-1);
            double sv0=0; for (int i:grp0) sv0+=sigma_hat[i][a]; sv0/=n0;
            tau2_00 = std::max(v0 - sv0, 0.0);
        }

        // MOM for tau2_{a,11} from c_i=1 group:
        // Var(theta_hat^L | c=1) = tau2_00 + tau2_11 + mean(Sigma^L),  x_i=(1,1)
        // so tau2_11 = sample_var(theta_hat^L in c=1 group) - mean(Sigma^L) - tau2_00
        double tau2_11 = 0.0;
        if (n1 > 1) {
            double m1=0; for (int i:grp1) m1+=theta_hat[i][a]; m1/=n1;
            double v1=0; for (int i:grp1){double d=theta_hat[i][a]-m1; v1+=d*d;} v1/=(n1-1);
            double sv1=0; for (int i:grp1) sv1+=sigma_hat[i][a]; sv1/=n1;
            tau2_11 = std::max(v1 - sv1 - tau2_00, 0.0);
        }

        // diagonal Sigma_pop: off-diagonals fixed at 0 (not identifiable)
        // small floor ensures invertibility
        Sigma_pop[a] = { std::max(tau2_00, 1e-8), 0.0,
                         0.0, std::max(tau2_11, 1e-8) };

        // closed-form MLE for mu_pop after Sigma_pop fixed (profile likelihood):
        //   mu_hat = (sum_i x_i x_i^T / v_i)^{-1} (sum_i x_i theta_hat^L_i / v_i)
        //   where v_i = x_i^T Sigma_pop x_i + Sigma^L_{i,a}
        M2  A = {0,0,0,0};
        Vec b = {0.0, 0.0};
        for (int i=0; i<n; ++i) {
            if (!has_data[i][a]) continue;
            Vec xi = {1.0, (double)env.context[i]};
            double v_i = quad2(xi, Sigma_pop[a]) + sigma_hat[i][a];
            if (v_i < 1e-20) continue;
            A = add2(A, scale2(outer2(xi), 1.0/v_i));
            b[0] += xi[0]*theta_hat[i][a]/v_i;
            b[1] += xi[1]*theta_hat[i][a]/v_i;
        }
        mu_pop[a] = matvec2(inv2(A), b);
    }

    // --- Step 3: EB posterior and action selection ---
    for (int i=0; i<n; ++i) {
        int a_sel;
        if (!has_data[i][0] || !has_data[i][1]) {
            a_sel = ud(rng);
        } else {
            Vec xi = {1.0, (double)env.context[i]};
            double reward_mean[2], reward_var[2];
            for (int a=0; a<2; ++a) {
                // KEY DIFFERENCE: rank-1 posterior update using x_i x_i^T —
                // only one scalar observation per participant, so the 2D
                // posterior is updated only in the direction of x_i
                // post_cov^{-1} = Sigma_pop^{-1} + (1/Sigma^L) * x_i x_i^T
                M2 Sp_inv       = inv2(Sigma_pop[a]);
                M2 post_cov_inv = add2(Sp_inv,
                                      scale2(outer2(xi), 1.0/sigma_hat[i][a]));
                M2 post_cov     = inv2(post_cov_inv);
                // post_mean = post_cov * (Sigma_pop^{-1} mu_pop + x_i theta_hat^L / Sigma^L)
                Vec rhs = matvec2(Sp_inv, mu_pop[a]);
                rhs[0] += xi[0]*theta_hat[i][a]/sigma_hat[i][a];
                rhs[1] += xi[1]*theta_hat[i][a]/sigma_hat[i][a];
                Vec post_mean = matvec2(post_cov, rhs);
                // project posterior onto participant's context to get
                // expected reward and variance for arm a
                reward_mean[a] = xi[0]*post_mean[0] + xi[1]*post_mean[1];
                reward_var[a]  = quad2(xi, post_cov);
            }
            // select arm with probability P(theta_{i,1} > theta_{i,0})
            double diff = reward_mean[1]-reward_mean[0];
            double sd   = std::sqrt(std::max(reward_var[0]+reward_var[1], 1e-20));
            a_sel = (ur(rng) < normal_cdf(diff/sd)) ? 1 : 0;
        }
        double mean_r = expected_reward(env, i, a_sel);
        double r      = mean_r + sigma_r*nd(rng);
        update_scalar(state[i][a_sel], r);
        total_regret += best_expected(env, i) - mean_r;
    }
}

Because only one context is observed per participant, EB assumes
$$\boldsymbol{\hat{\Sigma}}_a
=
\begin{pmatrix}
\hat{\tau}_{a,00}^2 & \tau_{a,01}=0 \\
\tau_{a,10}=0 & \tau_{a,11}^2
\end{pmatrix},$$
whereas in the underlying environment, it is possible to have covariance $\tau_{a,01}=\tau_{a,10}\neq0$. Since EB is unable to recover the diagonal elements, covariance that may originally have been due to $\tau_{a,10}$ and $\tau_{a,01}$ are attributed evenly to $\hat{\tau}_{a,00}^2$ and $\tau_{a,11}^2$.

The oracle knows that the true variability of the learning algorithm's estimates are as follows:
$$\text{Var}(\hat{\theta}^L_{i,a,t} \mid \boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a) = \boldsymbol{x}_i^\top\boldsymbol{\Sigma}_a\boldsymbol{x}_i+\Sigma_{i,a,t}^{L}=
\begin{cases}
\tau_{a,00}^2 + \Sigma^L_{i,a,t} & c_i = 0, \; \boldsymbol{x}_i = (1,0)^\top \\
\tau_{a,00}^2 + 2\tau_{a,01} + \tau_{a,11}^2 + \Sigma^L_{i,a,t} & c_i = 1, \; \boldsymbol{x}_i = (1,1)^\top
\end{cases}$$

EB's model isb accurate for participants where $c_i=0$; its estimates of the diagonals (coefficient variances) for $c_i=0$ are:
\begin{align*}
    \hat{\tau}_{a,00}^2 = \underbrace{\frac{1}{n_0 - 1}\sum_{i: c_i = 0}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{0,a,t}\right)^2}_{\text{total variability in } c_i = 0 \text{ group}} - \bar{\Sigma}^L_{0,a,t}
\end{align*}
In the above case, $\frac{1}{n_0 - 1}\sum_{i: c_i = 0}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{0,a,t}\right)^2$ estimates $\tau_{a,00}^2 + \bar{\Sigma}^L_{0,a,t}$; in other words, $\hat{\tau}_{a,00}^2$ estimates $\tau_{a,00}^2$.

However, EB's model is inaccurate for $c_i=1$. Specifically, its estimate of $\tau^2_{a,11}$, which is how heterogeneous $\theta_{i,a,1}$ (the effect of context) is across the population, becomes biased for both $a$.
\begin{align*}
    &\hat{\tau}_{a,11}^2 = \underbrace{\frac{1}{n_1 - 1}\sum_{i: c_i = 1}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{1,a,t}\right)^2}_{\text{total variability in } c_i = 1 \text{ group}} - \bar{\Sigma}^L_{1,a,t} - \hat{\tau}_{a,00}^2
\end{align*} 
Now, $\frac{1}{n_1 - 1}\sum_{i: c_i = 1}\left(\hat{\theta}^L_{i,a,t} - \bar{\theta}^L_{1,a,t}\right)^2$ estimates $\tau_{a,00}^2 + 2\tau_{a,01} + \tau_{a,11}^2 + \bar{\Sigma}^L_{1,a,t}$, and thus $\hat{\tau}_{a,11}^2$ estimates $\tau_{a,11}^2 + 2\tau_{a,01}$. 

If $\tau_{a,01}>0$, there is positive covariance between $\theta_{i,a,0}$ and $\theta_{i,a,1}$. This implies that there is an association between a participant's $\theta_{i,a,0}$ and the effect of their context when $c_i=1$, $\theta_{i,a,1}$. Intuitively, we might understand this as people who respond strongly at baseline get a strong boost because their $c_i=1$; people who respond weakly at baseline get less of a boost. In this scenario, $\hat{\tau}^2_{a,11}$ is too high because EB is unable to detect this covariance and attributes it to heterogeneity in $\theta_{i,a,1}$. It doesn't know participant $i$'s $\theta_{i,a,1}$ is high because $\theta_{i,a,0}$; it thinks $\theta_{i,a,1}$ is high simply because $\theta_{i,a,1}$ varies a lot in the population. Thus, it takes more of an unpooled approach, trusting the population-level means less and weighing the individual-level means more heavily.

Meanwhile, if $\tau_{a,01}<0$, there is negative covariance between $\theta_{i,a,0}$ and $\theta_{i,a,1}$. This implies participants with a high baseline get \textit{less} of a boost from their context.  In this scenario, $\hat{\tau}^2_{a,11}$ is too low; EB doesn't know that $\theta_{i,a,1}$ is lower because participant $i$'s $\theta_{i,a,0}$ was higher; instead, it thinks $\theta_{i,a,1}$ does not vary much in the population. Thus, it is more confident it and weighs the population-level means more heavily than it should. 

These two scenarios where $\tau_{a,01}>0$ and $\tau_{a,01}<0$ are meaningful to test because they can cause EB to act like a worse version of unpooled and pooled learning respectively. Since we typically work in \enquote{difficult} environments with low-to-moderate heterogeneity-to-noise ratios, we are specifically interested in the scenario where $\tau_{a,01}$ is negative, and pooled and EB are the two competing top performers. \nys{This was the scenario with the interesting graph we discussed.} When $\tau_{a,01}$ is negative, EB is pulled towards pooled behavior because it believes there is less heterogeneity than there actually is. \textit{However, EB still relies on individual estimates rather than pooled estimates in the learning step, weakening its performance in comparison to true pooled algorithms.} Thus, we conjecture that when $\tau_{a,01}$ is sufficiently negative, pooled algorithms will outperform EB. \nys{This matches what we see in the notable graphs we discussed for this environment, which are on slide 17: When we decrease the number of time points per individual, we expect individual learning to perform worse, and thus, when we change $T=200$ to $T=10$, we see the gap between EB and pooled's performance is reduced because EB's individual estimates are noisier. For $T=200$, EB always performs best; pooled sucks because EB has so much data and good individual-level estimates. However, for $T=10$, pooled performs better in several cases. Also, as expected, EB's regret increases with $P(c_i=1)$ ($x$-axis), since that's the case it estimates inaccurately.}

Below, we describe the scenario where there are two participant-specific context variables, one of which varies by time while the other does not. 

\subsectiontitle{True Environment}

There are two context variables that influence the participant's reward in this third scenario. The time-invariant context variable $c_{i}  \in \{0,1\}$ that represents an unchanging demographic characteristic of the participant, such as sex. The time-variant context variable $s_{i,t}$ can represent whether the participant is sick or healthy, which varies with time. Both are distributed $\text{Bern}(p)$, and $c_{i} \perp\!\!\!\perp s_{i,t}$.

In response to an action selected by the algorithm, the reward is generated as follows:

$$R_{i,t}(a) = \boldsymbol{\theta}_{i,a}^\top \boldsymbol{x}_{i,t} + \varepsilon_{i,t,a} = \theta_{i,a,0} + \theta_{i,a,1}c_i + \theta_{i,a,2}s_{i,t} + \varepsilon_{i,t,a}$$

Furthermore, each participant's parameters are drawn from a population-level hyper-distribution:
$$\boldsymbol{\theta}_{i,a} \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a), \text{ where } \boldsymbol{\mu}_a = \begin{pmatrix} \mu_{a,0} \\ \mu_{a,1} \\ \mu_{a,2} \end{pmatrix}, \text{ and } \boldsymbol{\Sigma}_a = \begin{pmatrix} \tau_{a,00}^2 & \tau_{a,01} & \tau_{a,02} \\ \tau_{a,01} & \tau_{a,11}^2 & \tau_{a,12} \\ \tau_{a,02} & \tau_{a,12} & \tau_{a,22}^2 \end{pmatrix}$$

Again, the $\{\theta_{i,a}\}_{i\in[n],a\in \{0,1\}} $ are independent. Furthermore, $\tau_{a,01}=\tau_{a,10}$, $\tau_{a,02}=\tau_{a,20}$, and $\tau_{a,12}=\tau_{a,21}$. 

\subsectiontitle{Learning Algorithm}

The learning algorithm does not have knowledge of the above environment. The model for the reward used by
the learning algorithm is

$$\hat{\boldsymbol{\theta}}_{i,a,t}^{L}
=
\left(
\lambda I +
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}^{L}(\boldsymbol{x}_{i,j}^{L})^\top
\right)^{-1}
\left(
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}^{L}\, r_{i,a,j}
\right)$$
where $\boldsymbol{x}_{i,j}^{L} = (1, s_{i,j})^\top$ and $\hat{\boldsymbol{\theta}}_{i,a,t}^{L}$ is equivalent to the $(\theta_{i,a,0} + \theta_{i,a,1}c_i,\ \theta_{i,a,2})^\top$ in the true underlying environment. Since only one context is observed per participant, $c_i$ is excluded from the $\boldsymbol{x}_{i,j}^{L}$ used in the regression by the learning algorithm.

From a Bayesian perspective, the ridge regression's prior is:

$$\boldsymbol{\theta}_{i,a}^{L} \sim \mathcal{N}(0, \tau_{0,a}^2 I), \quad \lambda = \frac{\sigma_{i,a}^{2,L}}{\tau_{0,a}^2} = 10^{-6}.$$

Equivalently, the prior mean is $0$, and the prior variance is $10^{-6}$ the unknown individual-level noise parameter, $\sigma_{i,a}^{2,L}$. 

The algorithm quantifies its uncertainty about the bivariate it produces as follows:

$$\boldsymbol{\Sigma}_{i,a,t}^{L}
=
\hat{\sigma}_{i,a,t}^2
\left(
\lambda I +
\sum_{j=1}^{n_{i,a,t}} \boldsymbol{x}_{i,j}^{L}(\boldsymbol{x}_{i,j}^{L})^\top
\right)^{-1}, \quad
\hat{\sigma}_{i,a,t}^2
=
\frac{
\sum_{j=1}^{n_{i,a,t}}
\left(
r_{i,a,j} - (\boldsymbol{x}_{i,j}^{L})^\top \hat{\boldsymbol{\theta}}_{i,a,t}^{L}
\right)^2
}{
n_{i,a,t} - 2
}.$$

Note that in the learning algorithm's world, $\hat{\boldsymbol{\theta}}_{i,a,t}^{L}$ is bivariate and $\boldsymbol{\Sigma}_{i,a,t}^{L}$ is a $2 \text{x}2$ matrix. 

\subsectiontitle{Action Selection Strategy}

\subsubsectiontitle{Empirical Bayes}

From the learning algorithm, the EB action selection strategy receives bivariate $\hat{\boldsymbol{\theta}}_{i,a,t}^{L}$ and a $2 \text{x}2$ matrix that measures the learning algorithm's uncertainty about its estimates, $\boldsymbol{\Sigma}_{i,a,t}^{L}$. Additionally, EB knows that $\boldsymbol{x}_{i,t}^{L} = (1, s_{i,t})^\top$.

$$\hat{\boldsymbol{\theta}}_{i,a,t}^{L} \mid \boldsymbol{\theta}_{i,a}
\sim
\mathcal{N}\!\left(\boldsymbol{D}_i^\top \boldsymbol{\theta}_{i,a},\, \boldsymbol{\Sigma}_{i,a,t}^{L}\right), \quad
\boldsymbol{D}_i^\top = \begin{pmatrix} 1 & c_i & 0 \\ 0 & 0 & 1 \end{pmatrix}$$

where $\boldsymbol{D}_i^\top \boldsymbol{\theta}_{i,a} = \begin{pmatrix} 1 & c_i & 0 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} \theta_{i,a,0} \\ \theta_{i,a,1} \\ \theta_{i,a,2} \end{pmatrix} = \begin{pmatrix} \theta_{i,a,0} + \theta_{i,a,1}c_i \\ \theta_{i,a,2} \end{pmatrix}$.

Then, EB believes the distribution of the estimates is:

$$\hat{\boldsymbol{\theta}}_{i,a,t}^{L} \mid \boldsymbol{\mu}_a, \boldsymbol{\Sigma}_a
\sim
\mathcal{N}\!\left(\boldsymbol{D}_i^\top \boldsymbol{\mu}_a,\;
\boldsymbol{D}_i^\top \boldsymbol{\Sigma}_a \boldsymbol{D}_i + \boldsymbol{\Sigma}_{i,a,t}^{L}\right)$$

And the posterior distribution is:

$$\boldsymbol{\theta}_{i,a} \mid \hat{\boldsymbol{\theta}}_{i,a,t}^{L}
\sim
\mathcal{N}\!\left(
\left(\hat{\boldsymbol{\Sigma}}_a^{-1} + \boldsymbol{D}_i (\boldsymbol{\Sigma}_{i,a,t}^{L})^{-1} \boldsymbol{D}_i^\top\right)^{-1}
\left(\hat{\boldsymbol{\Sigma}}_a^{-1}\hat{\boldsymbol{\mu}}_a + \boldsymbol{D}_i (\boldsymbol{\Sigma}_{i,a,t}^{L})^{-1} \hat{\boldsymbol{\theta}}_{i,a,t}^{L}\right),\;
\left(\hat{\boldsymbol{\Sigma}}_a^{-1} + \boldsymbol{D}_i (\boldsymbol{\Sigma}_{i,a,t}^{L})^{-1} \boldsymbol{D}_i^\top\right)^{-1}
\right)$$

Realistically, this could also occur if $c_t=t$—we expect the reward to change with how long the participants have been in the study—but in this case, the learning algorithm, which updates its beliefs over time, already takes this into consideration. Thus, we will not be exploring this setting.
