\begin{Large}
    \textsf{\textbf{Empirical Bayes: Two-Armed Bandit Simulation Outline}}   \par
    Statistical Reinforcement Learning Lab
\end{Large}

\vspace{2ex}

This is a two-armed bandit simulation. The basic notation is as follows: 
\begin{itemize}
    \item Participants ($i$): There are 50 participants denoted as $i=1, i=2, \dots, i=50$.
    \item Decision times ($t$): There are 11 decision times denoted as $t=0, t=1, t=2,\dots,t=11$. 
    \item Actions ($A$): At every time point, the participant chooses between two possible actions denoted as $a=0$ and $a=1$ respectively. 
    \item Reward ($R$): Based on the action the participant selects, the participant will receive a reward. $r$ may be equal to any real number. 
\end{itemize}

\textsf{\textbf {I. Defining the underlying environment}}

Every time a participant chooses an action, the underlying environment will generate a reward either completely at random (e.g., using a random number generator) or performing draws from distributions that may or may not be normal. \\

\textsf{\textbf {II. Learning algorithm}}

The learning algorithm will observe all  actions and rewards  up to and including time $t=11$ on individual $i$. Based on some method, the learning algorithm will estimate the value of a parameter called $\theta_{i,a}$ for each individual and action. These estimates will be called $x_{i,a,t}, i=1,...,50; t=11; a=0,1$.
The learning algorithm will also output a measure of its uncertainty in the estimate $x_{i,a,t}$ of the parameter $\theta_{i,a}$ for each individual and action.  This uncertainty is denoted by $\sigma_{i,a,t}$.

After each time point $t$, the learning algorithm will share updated $x_{i,a,t}, \sigma_{i,a,t}$ values with the action selection strategy. As there are 50 participants and 2 possible actions, the action selection strategy will receive a total of 200 data points at every time point.  \\
